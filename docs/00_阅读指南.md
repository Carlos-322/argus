# 00 从哪里开始

## 先使用项目

**查看过去的标注结果：双击项目根目录的 [查看已有结果.cmd](../查看已有结果.cmd)，输入结果编号即可。** 不需要 Key，不会重新分段或标注。

新的标注输出保存到 `data/review/任务名`，生成结果页面后会在下次打开入口时自动列出；已打开的选择菜单可以输入 `r` 刷新。

加热入口已支持“一次转换、多次标注”：原始数据不变时，改提示词、标签、模型或抽帧频率会复用视频和时间映射；每次的标注结果仍分开保存。缓存位置和失效条件见 [01 的转换复用说明](01_规范驱动的MCAP划分与标注需求.md)。

完整操作、结果保存位置、手动打开网页的方法，都在 **[Argus 本机使用说明](../Argus环境使用说明.md)**。

要按新版六子任务标注这批加热 MCAP，双击 `启动Argus.cmd`，输入 `1` 后按提示选择条目和运行方式，具体看 [01 的运行步骤](01_规范驱动的MCAP划分与标注需求.md)。打开菜单不会自动开始标注。其他通用标注可在主菜单输入 `3` 进入命令行，再按 [DeepSeek 使用说明](../local-dev/DeepSeek使用说明.md) 操作。
