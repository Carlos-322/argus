你正在处理双臂机器人加热工位视频。请按照以下公司规范划分步骤，
不要仅凭一般动作语义自由分段。

一、通用规则

1. 各步骤的开始、结束条件是分段的主要依据。
   步骤名称仅帮助理解，不能替代明确的边界判据。

2. 左臂、右臂均指机器人自身的左臂、右臂，不以画面左右判断。

3. 不要因为抓取、接触、松爪、调整或停顿，就在规定步骤内部
   额外分段；也不要因为相邻步骤具有相同目标而将其合并。

4. 只划分视频中实际发生的步骤，不强行补齐六段。
   不依据预期流程编造不可见动作或设备状态。

5. 明确要求衔接的相邻步骤共用时间分界。对于“上一段最后一帧”和“下一段
   第一帧”，应保留各自的帧归属，避免重复包含或遗漏。
   H5 与 H6 分别按各自的结束、开始条件划分，不强制共用时间分界。
   不得为了满足预期时长而改变明确可见的动作边界。

二、六个步骤及边界

H1：抵加热位保持

开始：
右臂夹持雪克杯开始往前运动之前。

结束：
左臂夹持纸杯开始往前运动之前。

注意：
雪克杯抵达加热位后保持不动的时间仍属于 H1。
不能在雪克杯刚到达加热位时提前结束。

H2：放纸杯腾左手

开始：
承接 H1 的结束边界。

结束：
左臂将纸杯放到桌面，松开夹爪，随后夹爪上移到高于纸杯的位置。

注意：
放下纸杯、松爪、夹爪上移共同属于本步骤。
不能在纸杯刚接触桌面或夹爪刚松开时提前结束。

H3：触控板按键

开始：
承接 H2 的结束边界。

结束：
左臂触发加热器成功、从触控板往回撤之前，
即最后一帧左手指尖仍在触控板上。

注意：
接近触控板、触碰按键，以及指尖在触控板上的停留时间，
均属于 H3。
首次离开触控板的帧属于 H4，不属于 H3。
如果设备成功状态不可见，不得仅凭接触推断触发成功；
仍应依据可见的接触和离开事件定位分界。

H4：离开触控板

开始：
左手指尖首次脱离触控板的第一帧。

结束：
左臂撤离触控板并向下运动，整个左夹爪首次降到显示屏
下边缘以下，即夹爪的最高点也已低于显示屏下边缘。

观察要求：
使用能同时清楚看到显示屏下边缘和左夹爪的指定参考机位，
在同一机位中判断二者的上下关系。
不能仅因指尖或夹爪的一部分低于显示屏，就认定步骤结束。

时间参考：
本步骤通常持续约 1–1.5 秒，允许随实际动作小幅变化。
视觉条件为主，时长为辅。
不要到达 1 秒就提前结束，也不要到达 1.5 秒就强制截断。
如果视觉判断与参考时长明显不符，应复核边界，
不要为了凑时长而移动边界。
遮挡或画面缺失时，不得仅凭参考时长认定视觉条件已满足。

H5：左手取回纸杯

开始：
承接 H4 的结束边界。
不需要等待夹爪已经接触纸杯或开始抓取。

结束：
左手取回纸杯，复位到 Home 并停止运动后，本步骤结束。

H6：从加热位撤回

开始：
右臂夹持雪克杯刚要回退 Home 之前。

结束：
右臂持雪克杯回到 Home，并静止不动。

注意：
不要在雪克杯刚离开加热位时提前结束。
到达 Home 后仍在运动时，也不视为结束。

三、模型执行要求

分段阶段：
保留原有时间坐标、窗口范围、跨窗口延续标记和 JSON 输出格式。
H1–H6 仅用于解释边界规则，不要求在原有分段 JSON 中增加字段。
当前窗口看不到完整步骤时，沿用跨窗口处理，不强行结束步骤。

描述阶段：
只描述指定目标区间实际发生的动作，不补写相邻步骤。
不修改目标区间的起止时间。
